# TG Summary Bot

[English](README.md) | **Русский**

Telegram-бот, который незаметно логирует сообщения в групповом чате и раз в день присылает дайджест обсуждений — с кликабельными ссылками на начало каждой темы.

Пример дайджеста:

> 📅 **Дайджест за 10.08.2026**
>
> 🔹 [Редизайн лендинга](https://t.me/c/xxx/201): Олег, Мария и Иван решили упростить шапку — убрать карусель и оставить один оффер.
> 🔹 [Оплата через СБП](https://t.me/c/xxx/205): Аня подняла вопрос про оплату, Мария предложила ЮKassa с меньшей комиссией.
>
> **Итог дня:** Продуктивный день — по каждой теме договорились о следующем шаге

## Как это работает

1. Бот сохраняет все текстовые сообщения и подписи к медиа из настроенных групп в локальную SQLite-базу (`data/messages.db`), включая цепочки реплаев.
2. Ежедневно в заданное время (`SUMMARY_TIME`, по умолчанию 22:00) сообщения за последние 24 часа форматируются в лог (`[HH:MM] Имя (ID: 123): текст`) и отправляются в LLM через [OpenRouter](https://openrouter.ai/).
3. LLM возвращает структурированный JSON: темы обсуждений, описание в одно предложение с именами участников и `start_message_id` каждой темы.
4. Бот собирает дайджест, где каждая тема — ссылка на первое сообщение обсуждения (`https://t.me/c/<chat_id>/<message_id>`), и присылает его в чат.
5. После успешной плановой отправки обработанные сообщения удаляются; записи старше 48 часов чистятся автоматически.

## Установка

```bash
git clone <repo-url> && cd tg-summary-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

| Переменная | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_GROUP_CHAT_IDS` | ID группы (или нескольких через запятую), например `-1001234567890` |
| `SUMMARY_TIME` | Время ежедневной отправки, `HH:MM` (по умолчанию `22:00`) |
| `TIMEZONE` | Таймзона для расписания и времени сообщений (по умолчанию `Europe/Moscow`) |
| `OPENROUTER_API_KEY` | Ключ [OpenRouter](https://openrouter.ai/) для генерации саммари |
| `LLM_MODEL` | Модель (по умолчанию `google/gemini-3-flash-preview`) |
| `DATABASE_PATH` | Путь к SQLite-базе (опционально, по умолчанию `./data/messages.db`) |

## Настройка в Telegram

1. Создайте бота у @BotFather и **отключите privacy mode** (`/setprivacy` → Disable) — иначе бот не будет видеть обычные сообщения в группе.
2. Добавьте бота в группу.
3. Отправьте в группе `/chatid` — бот ответит ID чата, впишите его в `TELEGRAM_GROUP_CHAT_IDS`.
4. Перезапустите бота.

## Запуск

```bash
python bot.py
```

## Команды

- `/summary` (или `/daily_summary`) — сгенерировать дайджест за последние 24 часа вручную (сообщения из базы не удаляются).
- `/chatid` — показать ID текущего чата.

## Примечания

- Ссылки формата `t.me/c/...` работают для супергрупп (ID начинается с `-100`) и открываются только у участников чата.
- Системный промпт для выделения тем лежит в [prompts/daily_summary.txt](prompts/daily_summary.txt) — его можно подстроить под стиль вашего чата.
- Внешняя база не нужна: всё хранится в одном SQLite-файле.
